# Examples

Use these examples to see how the implementation-planner skill turns source material into a buildable plan.

## `simple-feature-prd/`

A small fake PRD for saved grocery lists.

Files:

- `source-prd.md` — the source PRD / shaped package input
- `implementation-plan.md` — the filled output using `templates/implementation-plan.md`

This example demonstrates:

- readiness checking
- kickoff doc translation
- technical surface mapping
- risk/unknown registration
- task dumping
- task-group clustering
- dependency foliation
- parallelization judgment
- build sequencing
- vertical slices
- scope cuts
- acceptance checks
- tracker
- agent handoff packet

## `shapeup-message-drafts/`

A Shape Up-inspired case study based on the Message Drafts example from Chapter 12.

Files:

- `source-case-study.md` — a summarized source case study with the relevant scope logic
- `implementation-plan.md` — the filled output using the implementation-planner structure

This example demonstrates:

- scopes emerging from real work rather than arbitrary categories
- splitting a too-large scope into smaller integrated scopes
- preserving high-level scope language for project tracking
- dependency foliation across named scopes
- distinguishing dependency-parallel work from judgment-parallel work
- generating slices and handoff packets from a Shape Up-style case
