# Examples

Use these examples to see how the implementation-planner skill turns source material into a buildable plan.

## `simple-feature-prd/`

A small fake PRD for saved grocery lists.

Files:

- `source-prd.md` — the source PRD / shaped package input
- `implementation-plan.md` — the filled output using `templates/implementation-plan.md`

This example demonstrates:

- readiness checking
- kickoff doc translation
- technical surface mapping
- risk/unknown registration
- task dumping
- task-group clustering
- dependency foliation
- parallelization judgment
- build sequencing
- vertical slices
- scope cuts
- acceptance checks
- tracker
- agent handoff packet
